# 自定义关卡 JSON 格式

关卡编辑器导出的 JSON 可以直接复制、保存或再次导入。格式简单，适合手动编辑或做版本管理。

## 数据结构

```json
{
  "version": 1,
  "name": "我的关卡",
  "grid": ["..............."],
  "enemyCount": 12,
  "enemyMix": {
    "basic": 0.5,
    "fast": 0.25,
    "power": 0.2,
    "armor": 0.05
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `version` | number | 可选。当前版本为 `1` |
| `name` | string | 关卡名称，建议不超过 24 个字符 |
| `grid` | string[] | 必须为 15 行，每行 15 个字符 |
| `enemyCount` | number | 本关敌军总数，限制在 4–30 |
| `enemyMix` | object | 四类敌军的权重；可以是 0–1 的比例或百分比数值 |

`enemyMix` 会被自动归一化，总和不需要严格等于 1。四类敌军分别为：

- `basic`：普通
- `fast`：快速
- `power`：火力
- `armor`：装甲

## 地图字符

| 字符 | 地形 | 坦克可通过 | 子弹可通过 | 说明 |
| --- | --- | --- | --- | --- |
| `.` | 空地 | 是 | 是 | 默认地面 |
| `B` | 砖墙 | 否 | 摧毁后通过 | 可被子弹摧毁 |
| `S` | 钢墙 | 否 | 否 | 高等级玩家子弹可摧毁 |
| `T` | 树林 | 是 | 是 | 覆盖在坦克上方，提供视觉遮挡 |
| `W` | 水面 | 否 | 是 | 阻挡坦克，不阻挡子弹 |
| `I` | 冰面 | 是 | 是 | 坦克会略微加速 |

坐标原点在左上角，列为 `c = 0..14`，行为 `r = 0..14`。

## 固定区域

以下区域由游戏自动处理，编辑器也会锁定：

- **基地**：第 13–14 行、第 7–8 列，共 2×2 格。
- **基地围墙**：基地周围一格（第 12–14 行、第 6–9 列中除基地外的格子）。导入时，空白的围墙格会自动补成砖墙。
- **玩家出生点**：
  - P1：`(c=3, r=13)`
  - P2：`(c=11, r=13)`
- **敌军出生点**：
  - 左上：`(c=0, r=0)`
  - 中上：`(c=7, r=0)`
  - 右上：`(c=14, r=0)`

导入关卡时会自动清空基地和所有出生点周围 3×3 的区域，并补全基地空白的围墙格，避免出生即卡死。因此手动在 `grid` 中写入这些区域通常不会改变最终结果。

## 完整示例

```json
{
  "version": 1,
  "name": "中央花园",
  "grid": [
    "...............",
    "..BB.......BB..",
    "..BB.......BB..",
    "...............",
    ".....BBBBB.....",
    "....B.....B....",
    "...B..TTT..B...",
    "...B..TTT..B...",
    "....B.....B....",
    ".....BBBBB.....",
    "...............",
    "...............",
    "......BBBB.....",
    "......B..B.....",
    "......B..B....."
  ],
  "enemyCount": 12,
  "enemyMix": {
    "basic": 0.5,
    "fast": 0.25,
    "power": 0.2,
    "armor": 0.05
  }
}
```

## 导入与导出

### 在编辑器中

1. 主菜单 →「关卡编辑器」。
2. 将 JSON 粘贴到右下角「关卡 JSON」文本框。
3. 点击「导入 JSON」。
4. 点击「单人试玩」或「双人试玩」立即游玩。
5. 点击「保存关卡」写入浏览器本地存档；点击「下载 JSON」导出文件。

「复制 JSON」会把当前编辑器中的地形和配置导出到剪贴板。

### 保存位置

关卡保存在浏览器 `localStorage` 的 `tank-battle-custom-levels-v1` 键下。清除浏览器站点数据会删除这些本地关卡。

## 校验规则

导入时会执行以下检查：

- `grid` 必须是 15 行数组。
- 未知地形字符会按空地处理。
- `enemyCount` 会被限制在 4–30 之间。
- `enemyMix` 全为 0 或缺失时会回退到默认敌军构成。
- 基地、围墙、出生点区域会按上文规则修正。

如果 JSON 无法解析或缺少 `grid`，编辑器会提示导入失败。
